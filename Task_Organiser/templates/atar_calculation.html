How ATAR is Calculated

Overview

The Australian Tertiary Admission Rank (ATAR) is a percentile ranking system used by universities in Australia to select students for undergraduate courses. Our calculator estimates your ATAR using the same methodology as UAC (Universities Admissions Centre).

Step 1: Raw HSC Marks

Input: Your raw HSC marks for each subject (0-100 for standard subjects, 0-50 for extensions)

Validation: We check that marks are within valid ranges for each subject type

Example: English Advanced: 85/100, Mathematics Extension 1: 35/50

Step 2: Subject Scaling

What is Scaling? Different subjects have different levels of difficulty. UAC applies scaling to make marks comparable across subjects.

Our Method: We use polynomial regression models trained on real UAC scaling data to convert raw marks to scaled marks.

Scaling Examples:
Subject Raw 85 Scaled Scaling Factor
Mathematics Advanced 85/100 72.9% 0.86×
Physics 85/100 79.1% 0.93×
English Standard 85/100 74.1% 0.87×
Design & Technology 85/100 62.6% 0.74×
Note: Scaling factors vary by mark level. Higher marks often scale differently than lower marks.

Step 3: Aggregate Score

What is Aggregate? Your ATAR aggregate is the sum of your best 10 units of scaled marks.

Aggregate Rules:
  • Must include: At least 2 units of English (any level)
  • Maximum: 10 units total (typically 5 subjects)
  • Best units: We select your highest-scoring units

    • Maximum possible: 500.0 (10 units × 50.0 per unit)

Example Calculation:

Step 4: ATAR Conversion

Final Step: Convert your aggregate score to an ATAR using UAC's published conversion table.

Technical Details

Polynomial Regression Models:

We use degree-4 polynomial regression trained on UAC scaling data for each subject. This provides more accurate scaling than simple linear interpolation.

Machine Learning Implementation:
Library Usage Purpose
scikit-learn PolynomialFeatures Creates polynomial features for regression (degree 4)
scikit-learn LinearRegression Fits polynomial model to scaling data points
scikit-learn make_pipeline Combines preprocessing and regression steps
numpy np.array() Converts scaling data to numpy arrays
numpy np.clip() Ensures scaled marks stay within 0-100 range
numpy np.reshape() Prepares data for model input
Code Implementation Example:
# Create polynomial features (degree 4)
poly_features = PolynomialFeatures(degree=4, include_bias=False)
X_poly = poly_features.fit_transform(X.reshape(-1, 1))

# Fit linear regression model
model = LinearRegression()
model.fit(X_poly, y)

# Predict scaled mark for new HSC mark
new_mark_poly = poly_features.transform([[hsc_mark]])
predicted_scaled = model.predict(new_mark_poly)[0]

# Ensure result is within valid range
scaled_mark = np.clip(predicted_scaled, 0, 100)
Data Sources:
  • UAC Official Scaling Reports: Historical scaling data for all HSC subjects
  • ATAR Conversion Tables: Published aggregate-to-ATAR conversion breakpoints
  • Subject Difficulty Adjustments: Account for varying subject difficulty levels
Accuracy Considerations:
  • Historical Data: Based on past years' scaling patterns
  • Methodology Changes: UAC may update calculation methods
  • Cohort Variations: Your school's performance may affect scaling
Calculator Limitations

This calculator provides estimates only and should not be used for official purposes:

  • Does not account for school-specific scaling adjustments
  • Based on historical data, not current year methodology
  • Cannot predict assessment performance variations
  • Official ATAR calculations may use different factors
